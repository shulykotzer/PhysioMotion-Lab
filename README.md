# PhysioMotion Lab

מעבדה קלינית לניתוח תנועה ונוירולוגיה, לסטודנטים לרפואה ולסיעוד. האפליקציה משתמשת במד התאוצה של הטלפון (DeviceMotionEvent) כדי למדוד:

- **בדיקה A – יציבות יציבתית ואטקסיה:** מבחן רומברג (עיניים פקוחות מול עיניים עצומות, טנדם, שכרות, לאחר מאמץ). מדדים: נדנוד RMS, תאוצת שיא, אורך מסלול ומהירות נדנוד, יחס רומברג.
- **בדיקה B – הערכת רעד:** רעד מנוחה פרקינסוני (3–6 Hz) מול רעד פיזיולוגי (8–12 Hz). מדדים: משרעת שיא, תדר דומיננטי, חלוקת הספק לרצועות, ציון חומרה.

כוללת השוואת שני מצבים בגרף, טבלת מדדים, רשומות קליניות וייצוא דוח PDF בעברית.

## הפעלה

כל האפליקציה היא קובץ אחד: `index.html`.

- **בטלפון:** יש לפתוח את הדף מכתובת **https** (למשל GitHub Pages). בלי https הדפדפן חוסם את חיישני התנועה.
- **במחשב:** אפשר לפתוח את הקובץ ישירות ולהפעיל "הדמיית נתוני חיישן" או "טעינת הקלטות הדגמה".

הוראות שימוש מפורטות מופיעות בתוך האפליקציה, בכרטיס "איך משתמשים במעבדה".
