# PhysioMotion Lab

מעבדה קלינית לניתוח תנועה ונוירולוגיה, לסטודנטים לרפואה ולסיעוד. האפליקציה משתמשת במד התאוצה של הטלפון (DeviceMotionEvent) כדי למדוד:

- **בדיקת יציבות (טורקיז):** מבחן רומברג. תנוחות: עיניים פקוחות, עיניים עצומות, עמידת טנדם. מדדים: נדנוד RMS, תאוצת שיא, אורך מסלול ומהירות נדנוד, יחס רומברג.
- **בדיקת רעד ביד (סגול):** רעד מנוחה פרקינסוני (3–6 Hz) מול רעד פיזיולוגי (8–12 Hz). תנוחות: יד נתמכת במנוחה, יד מושטת, מנוחה עם הסחת דעת. מדדים: משרעת שיא, תדר דומיננטי, חלוקת הספק לרצועות, ציון חומרה.

בכל בדיקה בוחרים לפחות 2 מתוך 3 התנוחות. התנוחה הראשונה היא הבסיס, וכל השאר מושוות אליה. אפשר לציין גם את מצב הנבדק/ת (אחרי מאמץ, קפאין, עייפות, הדמיית שכרות). כוללת השוואה בגרף, טבלת מדדים, רשומות קליניות וייצוא דוח PDF בעברית.

## חיבור הטלפון למחשב

כל סטודנט/ית יכול/ה לעבוד רק בטלפון, או לחבר את הטלפון למחשב האישי: פותחים את הקישור במחשב, ובשלב 1 מופיע קוד QR. סורקים אותו בטלפון, ומאותו רגע כל פעולה באחד המכשירים מופיעה גם בשני: בחירת הבדיקה והתנוחות, התחלת מדידה (ההקלטה עצמה תמיד בטלפון), התוצאות, השם, התצפיות והמסקנה. אפשר להוריד את הדוח מכל אחד מהם.

לכל מחשב יש קוד חיבור אקראי משלו, כך שרק הטלפון שסרק אותו מתחבר אליו. החיבור עובר דרך שרת MQTT ציבורי וחינמי (HiveMQ, ו-EMQX כגיבוי), כי GitHub Pages הוא אתר סטטי. אם השרת לא זמין, הטלפון ממשיך לעבוד לבד כרגיל.

## הפעלה

כל האפליקציה היא קובץ אחד: `index.html`.

- **בטלפון:** יש לפתוח את הדף מכתובת **https** (למשל GitHub Pages). בלי https הדפדפן חוסם את חיישני התנועה.
- **במחשב:** אפשר לפתוח את הקובץ ישירות ולהפעיל "נתוני דמה" או "דוגמה מוכנה".

האפליקציה מובילה את הסטודנטים בחמישה שלבים ממוספרים: הפעלת החיישן (או חיבור הטלפון), בחירת בדיקה, בחירת תנוחות ומדידה, תוצאות ודוח.
